🚀 Installation

Termux (Android)

1. Update packages

pkg update -y && pkg upgrade -y

2. Install requirements

pkg install git nodejs -y

3. Clone the repository

git clone https://github.com/UnclK1ra/Kira-Bot.git

4. Enter the project folder

cd Kira-Bot

5. Install dependencies

npm install

6. Start the bot

npm start
